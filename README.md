# Lab 03 — Chaotic Text Generator

Interactive Streamlit test bench comparing three text generators on a small **synthetic** tagged corpus: a plain first-order Hidden Markov Model (HMM), a role-split HMM, and a trigram baseline. The models and log-space Viterbi decoder are in `src/pipeline.py` (provided starter code).

## Features

- Sidebar: model, temperature (0.3–3.0), reproducible random seed and 10–500 generated sentences.
- Per-sentence words, POS tags, valid/invalid patterns, subject–verb plausibility, and training-copy indicators.
- Four batch metrics: valid tag pattern, plausible subject–verb, novel sentences, distinct-2.
- Interactive Viterbi POS tagger with **visible unknown-word warning** and smoothed decoding.
- CSV export, cross-model comparison, and temperature-vs-validity plot.

**Important:** This corpus is synthetic and has a tiny grammar. Its metrics are relative to the corpus and do not assess real-English quality.

## Quick start

Python 3.10+ is recommended. Run from the folder containing `app.py`:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.evaluate
streamlit run app.py
```

The app opens locally in a browser, usually on `http://localhost:8501`.

## Real text evaluation

```bash
python -m src.evaluate_real
```

This downloads the UD English EWT train/test sets from the Universal Dependencies repository on the **first** run, then writes `results/ewt_results.json`. An online connection is needed for first-time download. `results/ewt_results.json` was regenerated by a fresh run (HMM+Viterbi 88.0% token accuracy).

## Deployment (Streamlit Community Cloud)

1. Create a GitHub repository and push `app.py`, `requirements.txt`, `src/`, `data/corpus.csv`, `results/metrics.json` and this README.
2. In [Streamlit Community Cloud](https://share.streamlit.io), create an app from the repository, choosing `app.py` at the repository root.
3. Test the public URL in a private window: generate 100 sentences, tag an unknown word, and download a CSV.
4. Add your deployed URL to the submission (two local screenshots are in `screenshots/`).

No public app or GitHub repository has been created by this deliverable. Deployment requires access to your own accounts.

## Test commands

```bash
python -m compileall -q app.py src
python -m src.evaluate
python -m src.evaluate_real  # requires internet, once
```

The synthetic evaluation splits by document (960 training / 240 test sentences). Each setting uses 500 generated sentences, seed 42. The saved real-data metrics come from a fresh evaluation of UD English EWT (12,544 training / 2,077 test sentences).

## Files

- `app.py` — Streamlit UI
- `src/pipeline.py` — HMM, Viterbi, trigram and metrics (starter implementation)
- `src/evaluate.py` — synthetic evaluation and saved results
- `src/evaluate_real.py` — download + real-data evaluation
- `data/corpus.csv` — required synthetic dataset
- `results/` — original and regenerated evaluation results
- `report_lab03.pdf` — concise report
